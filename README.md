# 네이버 콘텐츠 기회 분석기 V2.4

- 키워드 분석 후 검색형/홈판형/혼합형 적합도를 보여줍니다.
- AI는 작성 유형을 자동 선택하지 않습니다. 사용자가 직접 선택합니다.
- 선택한 유형에 따라 제목 후보와 글쓰기 규칙이 달라집니다.
- 홈판형: 공백 제외 약 1,500~2,000자, 이미지 계획 최소 5개.
- 검색형: 공백 제외 3,000자 이상, 검색 의도와 공식 출처 우선.
- 혼합형: 공백 제외 약 2,500~3,500자.
- 지원금·축제·정부정책·공공정보는 공식 페이지 URL과 확인 사실을 함께 제공합니다.
- 쿠팡파트너스는 제품 추천 글에서만 선택적으로 1개 고려하며 필수가 아닙니다.
- 애드센스 유도용 외부링크는 사용하지 않습니다.
- 내 블로그 전체 자동 검색은 하지 않으며 특정 기존글 URL을 입력한 경우에만 비교합니다.
