# 네이버 콘텐츠 기회 분석기 V2.4

## 기본 흐름
1. Creator Advisor에서 키워드 찾기
2. 키워드 입력
3. [선택] 벤치마크 블로그 URL 입력
4. 키워드 분석
   - 검색어 트렌드
   - 블로그
   - 뉴스
   - 웹문서
   - 이미지
   - 최신·공식 웹문서 보강 검색
   - 필요 시 쇼핑인사이트
   - AI 콘텐츠 전략 분석
5. AI가 작성 후보 제목 3개 제시
6. 사용자가 실제 작성할 제목 1개 선택
7. 선택한 제목을 기준으로 글 작성

## 내 블로그/기존글
- 사이드바의 `네이버 블로그 주소 또는 ID`는 기준 정보로만 보관합니다.
- 내 블로그 전체 자동 검색은 하지 않습니다.
- `특정 기존글 URL(선택)`을 입력했을 때만 해당 글을 콘텐츠 자산으로 비교합니다.
- 기존글 URL이 없어도 키워드 분석 → 제목 선택 → 글 작성이 정상 진행됩니다.
- 벤치마크 블로그 URL은 내 기존글 URL과 별개이며 경쟁/참고 콘텐츠용입니다.

## 최신 정보 검증 강화
시의성이 강한 키워드는 `키워드 공식`, `키워드 최신`, 상업 키워드는 `키워드 할인 쿠폰` 웹검색을 추가합니다. 상위 후보 페이지도 직접 짧게 확인해 최신 할인율·기간·코드 등을 근거 기반으로 작성하도록 AI에 전달합니다.

근거가 없는 최신 정보는 작성하지 않도록 프롬프트에서 제한합니다.

## 이미지
이미지 계획은 기본적으로 실사 사진 중심입니다. 인포그래픽과 이미지 내부 텍스트는 기본값으로 사용하지 않습니다.

## 검색 요약문
`Meta description`은 `검색 요약문 (참고용)`으로 표시합니다. 네이버 스마트에디터에 별도로 입력하는 필수 필드가 아니며, 본문 복사 시 자동 입력된다고 가정하지 않습니다.

## Gemini 429
- 일시적인 429/503: 제한적 재시도 + 지수 백오프
- 일일 quota 초과: 재시도하지 않고 중단 및 안내


## V2.4 핵심 변경
- 작성 유형을 `AUTO / HOME_FEED / SEARCH / HYBRID`로 분리했습니다.
- 홈판형: 공백 제외 1,500~2,000자 목표, 반전·숫자·의외성·상황·경험형 제목/Hook, 이미지 최소 5개 슬롯을 설계합니다.
- 검색형: 공백 제외 3,000자 이상을 목표로 하며 검색 의도와 정보 정확성을 우선합니다.
- 모든 글은 공백 제외 1,500자 이상을 기본 하한으로 합니다.
- 지원금·정부정책·축제·공공정보 등은 공식 페이지 후보를 웹검색 단계에서 보강하고, AI가 확인된 공식 URL과 핵심 사실을 `official_sources`에 기록합니다.
- 외부링크는 필수가 아닙니다. 애드센스 유도용 링크는 사용하지 않고, 쿠팡파트너스는 제품 추천 글에서만 최대 1개 선택 슬롯으로 제안합니다.
- 이미지 계획은 본문 완성 후 `insert_after / role / need_score / Pixabay 검색어 / AI prompt / ALT`까지 설계합니다.
- 실제 Pixabay 다운로드/AI 생성은 다음 Image Worker 단계에서 연결할 수 있도록 구조를 확장했습니다.
