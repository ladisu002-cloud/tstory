# 티스토리 건강 블로그 원고생성기

보이스 오브 피트니스, 수퍼푸드 같은 tvN 건강 프로그램의 예고/하이라이트를 소재로,
웹검색으로 배경지식을 보강해서 티스토리용 건강 정보 글을 만드는 도구입니다.
발행은 자동화하지 않고 완성된 원고를 복사해서 티스토리 편집기에 직접 붙여넣는 방식입니다.

## Streamlit Cloud 배포 방법

1. 이 폴더의 `streamlit_app.py`, `requirements.txt`를 GitHub 저장소 루트에 올립니다.
2. Streamlit Cloud "Deploy an app" 화면에서:
   - Repository: 본인 저장소 (예: `ladisu002-cloud/tstory`)
   - Branch: `main`
   - **Main file path: `streamlit_app.py`** (이 이름과 실제 파일명이 정확히 같아야 "This file does not exist" 오류가 나지 않습니다)
3. 배포 후 앱 화면 오른쪽 위 "⋮" 메뉴 → Settings → Secrets에 아래처럼 입력해두면
   매번 키를 직접 입력하지 않아도 됩니다.

```
GEMINI_API_KEY = "여기에-발급받은-키"
PIXABAY_API_KEY = "여기에-발급받은-키(선택)"
```

## 로컬에서 실행하고 싶다면

```bash
pip install -r requirements.txt
cp env.example .env   # .env 파일에 API 키 입력
streamlit run streamlit_app.py
```

Gemini API 키는 https://aistudio.google.com/apikey 에서 발급받습니다.
Pixabay API 키(선택)는 https://pixabay.com/api/docs/ 에서 무료로 즉시 발급받을 수 있습니다.

## 왜 방송 페이지를 자동으로 안 긁어오나요?

tvN 공식 사이트(cjenm.com)는 robots.txt로 자동 접근 자체를 막아두고 있어서, 이 사이트를
대상으로 한 자동 스크래핑 기능은 만들지 않았습니다. 대신 방송 페이지에서 예고/하이라이트
제목이나 설명을 직접 복사해서 앱에 붙여넣으면(30초 정도 소요), 그 다음 단계인 배경지식
검색·글쓰기·이미지 생성은 전부 자동으로 진행됩니다.

## 사용 순서

### 하나씩 만들기 탭
1. 프로그램을 고르고, 방송 페이지에서 복사해온 예고/하이라이트 문구를 붙여넣습니다.
2. "관련 정보 검색"으로 Gemini의 Google 검색 연동 기능이 그 주제에 대한 배경지식을 찾아옵니다.
3. 제목 후보를 고르고 본문을 생성합니다. 과장된 효능 주장은 피하고 "전문의와 상담" 문구가
   자연스럽게 들어가도록 프롬프트에 포함해뒀습니다.
4. 본문에서 이미지 프롬프트를 뽑아 AI 이미지 생성(Pollinations, 무료) 또는 실사 스톡사진
   검색(Pixabay)으로 이미지를 받습니다.
5. 제목/본문을 복사하고 이미지를 다운로드해서 티스토리 편집기에 직접 붙여넣습니다.

### 여러 주제 한 번에 생성 (배치) 탭
1. 주제를 한 줄에 하나씩 입력합니다 (최대 30개). 방송 소재가 아니어도 되고,
   일반적인 건강/생활 주제도 가능합니다.
2. 왼쪽 사이드바의 글쓰기 유형·웹 리서치 설정을 그대로 사용해서 "전체 순차 생성"을 누르면
   각 주제마다 (선택)배경지식 검색 → 제목 → 본문까지 자동으로 순서대로 생성합니다.
3. 완료되면 주제별로 접었다 펼 수 있는 결과 목록이 나옵니다. 마음에 드는 것부터
   복사해서 티스토리에 붙여넣으면 됩니다. 이미지는 "하나씩 만들기" 탭에 본문을
   붙여넣어 따로 생성할 수 있습니다.
