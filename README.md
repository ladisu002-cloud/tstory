# 네이버 콘텐츠 기회 분석기 V2.4.1

## 이번 수정

- 분석 결과를 탭이 아닌 **2열 × 3행 카드 그리드**로 표시합니다.
- 각 분석 카드는 내부 스크롤을 사용해 화면이 불필요하게 길어지는 것을 줄였습니다.
- 카드 순서: **키워드 분석 → 경쟁 콘텐츠 → 콘텐츠 GAP → 홈판 전략 → 추천 키워드 → 내 기존글**
- **내 기존글은 마지막 카드**에 배치했습니다.
- 키워드 분석의 `연관 키워드 / 롱테일 키워드 / 제목 패턴` 글자 크기를 작게 조정했습니다.
- 왼쪽 사이드바의 **작성 유형 기본값을 제거**했습니다.
- 키워드 분석 단계에서는 **글작성용 추천 제목을 자동으로 기본 선택하지 않습니다.**
- 분석 단계에서는 검색 적합도/홈판 적합도만 보여주고, 사용자가 **검색형 / 홈판형 / 혼합형** 중 직접 선택합니다.
- 작성 유형을 선택한 뒤에만 해당 유형에 맞는 **추천 제목 3개**를 생성하고, 그중 하나를 사용자가 선택합니다.
- 선택한 유형과 제목을 그대로 글 작성에 전달합니다.
- 네이버 검색광고 API의 `/keywordstool`을 연결했습니다.
  - Access License Key
  - Secret Key
  - Customer ID
  - 설정 화면에서 Gemini/NAVER API와 함께 입력하고 저장
- 입력 키워드 기준 연관/추천 키워드와 **월간 PC 검색량, 모바일 검색량, 합계, 경쟁도**를 표시합니다.
- 검색광고 API는 조회 전용으로 사용하며 캠페인/입찰/예산을 변경하지 않습니다.

## 네이버 검색광고 API

공식 서비스 URL은 `https://api.searchad.naver.com`이며 `/keywordstool`에서 `hintKeywords`와 `showDetail=1` 등을 이용해 키워드 도구 데이터를 조회합니다.

검색광고 API 인증은 `X-Timestamp`, `X-API-KEY`, `X-Customer`, `X-Signature` 헤더를 사용합니다.

월간 PC/모바일 검색량 필드는 `monthlyPcQcCnt`, `monthlyMobileQcCnt`, 경쟁도는 `compIdx`를 사용합니다.

## 주의

검색광고의 월간 검색량은 검색광고 키워드 도구 데이터이며 네이버 유기적 검색 노출량과 동일한 값으로 해석하지 않습니다.

API 키는 GitHub에 하드코딩하지 말고 Streamlit Secrets 또는 앱의 설정 화면을 사용하세요.
